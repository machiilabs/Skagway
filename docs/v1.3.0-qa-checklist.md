# Skagway 1.3.0 — Human QA checklist

Feature freeze on `feat/1.3.0`. No new features. Walk these on a Mac with the installed app (`/Applications/Skagway.app`). Unit tests cover clamp / HUD attach / captions / Reconnect preview / column math; this list is the UI you still have to see.

**Build under test:** 1.3.0 (1169) unless a later freeze commit bumped it.

---

## Launch & browse

- [ ] Launch Skagway. Library opens; Grid / List / Storyboard all switch without a blank wall.
- [ ] **Grid** — cards, selection, Inspector content when a video is selected.
- [ ] **List** — rows, sort, selection.
- [ ] **Storyboard** — 2×3 collage, click a cell seeks/plays that time, poster/title still readable.
- [ ] **Compact density** (Storyboard) — Inspector **shown** → 3 columns; Inspector **hidden** → 4 columns. No multi-second stall, no card flash/remount. **Normal** stays ≤ 3 columns on a wide pane.

## Scroll HUD (rolodex)

- [ ] Scroll Grid, List, and Storyboard. Sort-index chip appears beside the wall scrollbar thumb (not over the Inspector).
- [ ] Chip updates while the finger/mouse is still scrolling (live, not only after bounce).
- [ ] Chip is gone (or fades) when idle.

## Inspector ⌘I (after a long scroll)

Do this **after scrolling deep** into a large Storyboard/Grid so the pin + clip path is dirty.

- [ ] **Hide (⌘I)** — wall expands immediately. Compact Storyboard goes 3→4. App does not crash.
- [ ] **Show (⌘I)** — Inspector **paints immediately** (hero / metadata, not a blank column). Last divider width comes back (3 columns again in Compact). Wall does not remount.

### Known 1166–1169 regressions (must not return)

| Build | Failure | Pass looks like |
| --- | --- | --- |
| **1166** | Show Inspector = **blank pane**; divider **not** last width | Content paints; divider matches last shown width |
| **1167** | Show Inspector **stalls** 2–3s (or park-host blank) | Show is as cheap as hide; pane stays arranged and clipped |
| **1168 / 1169** | Scroll HUD **missing** (chip on 0×0 host, or Inspector scroller) | Chip on the **wall** scroller while scrolling |

## Reconnect & missing-file banner

- [ ] Missing-file banner uses **video / videos** (never “1 videos”). CTA is **Reconnect…**.
- [ ] **Reconnect…** preview: Ready / Needs attention / Still missing counts match the files you pointed at. Duplicate evidence paths appear once.
- [ ] Apply reconnects Ready files; Needs attention stays until you include it.

## Player: filmstrip & captions

- [ ] Play a video. In-player filmstrip sits above the scrubber (thinner in Compact player). Drag/click is **continuous / linear** with the playhead, not jumpy cell-only.
- [ ] **Captions** menu: Off / sidecar / in-band. No “Media group N”. Real language names (e.g. English SDH).

## Collection pill

- [ ] Collect 2+ videos. Header pill reads **N videos collected**. Click opens Inspector batch; × clears the set.

---

## Fail / stop

Any 1166–1169 symptom, ⌘I crash, Compact stuck at 3 after hide, HUD on the Inspector, or “Media group N” in Captions → fail the freeze; do not add features to paper over it.
