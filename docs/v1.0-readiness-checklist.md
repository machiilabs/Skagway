### Clarifications (2026-09-03)

**Notes vs custom field.** There is no strong need for a built-in Notes column. Custom metadata already has type **Text** (multiline). Users can add a field named Notes (or anything else); it appears in the Inspector, Sort, List columns, Advanced Filter / collections, search, and export. A first-class field would only be justified if every library must have Notes without setup, or if we needed a special UI (always-on Inspector block, dedicated shortcut). That is not a 1.0 requirement.

**`os_signpost` (what it is).** Apple’s interval markers in Unified Logging (`import os` / `OSSignposter`). You wrap a hot path (`beginInterval` / `endInterval`); Instruments’ Points of Interest and `log show --predicate 'subsystem == "…"'` show how long that interval took. `GRID-PERFORMANCE.md` proposed signposts around `applyFilteredVideos`, grid `scrollTo`, thumbnail generate, and `contentHost.rootView =`. **None of that was implemented** (or it was removed). It is a **developer profiling aid**, not user-facing, not required to ship 1.0. Step 2 can use Instruments Time Profiler instead; add signposts only if we want repeatable named timings in the log.
