## Pass bar (12k, already-indexed library)

| Scenario | Pass | Fail |
| --- | --- | --- |
| Cold start to usable grid | Window + first screen of cards within **~8 s**; app not beachballed | Spin / unresponsive **>15 s** |
| Filter / search apply | Result count updates within **~2 s**; window stays clickable | Multi-second freeze; beachball |
| Scroll / Home / End | Continuous motion; brief thumbnail pop-in OK | Stutter that stalls the scroll, or **>2 s** freeze |
| Sort (same membership) | Reorder without full-grid “flash rebuild” | Whole grid tears down / long hitch |
| Select 1, then 20 | Inspector updates; grid does not re-layout | Grid hitch or inspector lag **>1 s** |
| Play / Esc | Player opens/closes without reshaping or rebuilding the wall | Wall relayout, scroll jump, or long hitch |

Thumbnail **backfill** while scrolling (placeholders → stills) is expected and is not a fail by itself.
